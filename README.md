# Tools for manipulating spectrograms from SDRIQ files collected during the NASA Artemis mission

This repo contains a few tools for studying SDRIQ files recorded with SDRAngel during American University's attempt to track the Artemis II Orion spacecraft Integrity during its flight to the moon.  The spacecraft was transmitting an S-band beacon at 2216.5 MHz, so most of the tools are oriented toward extracting information near that frequency.
